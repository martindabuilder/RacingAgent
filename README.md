# RacingAgent
Intelligent Agent project for university, using Panda3D for the 3D graphics and physics engine, Gymnasium for the agent and environment, and PPO for the agent training method and algorithm.
[Car chosen is the Mercedes AMG W11. The 3D model for it is taken from Sketchfab](https://sketchfab.com/3d-models/2020-f1-mercedes-benz-w11-6c0e669402c34133b4b516f4ca2ba9e4)
[For now there is only one available track in the project, that is the Yas Marina Abu Dhabi Circuit, information for it was taken from this github repo](https://github.com/f1tenth/f1tenth_racetracks/tree/main)
[Gymnasium car racing environment](https://gymnasium.farama.org/environments/box2d/car_racing/)
